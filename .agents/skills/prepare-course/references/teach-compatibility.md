## 適用邊界

- 引用 teach 的教學設計、短篇 HTML、互動回饋、速查文件、來源管理與元件復用。實際細節讀取當前原檔，不在此複製其全文或依賴固定標題／行號。
- MISSION／RESOURCES 格式於建立或改寫這些文件時讀取；學習目的是已確認 spec 的摘要，不是額外的個人學習計畫。
- prepare-course 的單元工作區路徑、教材狀態、Git 操作界線與知識庫限制由本專案維護，不隨 teach 自動改變。尤其個人學習紀錄與依掌握程度調整任務的要求，不適用本專案。

## 原檔更新時

1. 製作教材時讀取當前 teach，計算內容指紋。實際使用 MISSION／RESOURCES 格式時也比對對應檔案。
2. 指紋不同只代表內容變更。利用 Git 可取得的差異，或直接重讀當前檔案，重新核對上面的引用範圍、路徑含義與專案差異；不要依舊有摘要猜測新要求，也不要只因雜湊變動要求學生批准。
3. 相容的改進可直接採用；在本次教材製作紀錄寫下實際參照的指紋與核對結果。維護本 skill 時，再更新這份基準的日期與指紋，不將每次備課擴大為修改 skills。
4. 若變更抵觸專案或學生指示，沿用本專案已確認的邊界，說明採用的差異。只有無法從既有規格判斷、且會實質改變教材範圍的問題才詢問學生；可獨立完成的工作繼續進行。
5. 連結失效時先在本專案搜尋原 skill／格式檔的新位置並核對內容；若無法取得必要參考，說明缺少的檔案與受影響工作，不以本指紋表冒充參考內容，也不從網路自動換裝另一個版本。
