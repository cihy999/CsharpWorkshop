## 題目一：🔍 程式碼填空

下方是 `EventHandler` 版本的 `Author.Publish()` 方法，請填入空格：

```csharp
public void Publish(Article article)
{
    Article createdArticle = article.Create();
    string subscriberUpdateMessage = createdArticle.ToString();
    OnPublish?.____(____,  new PublishEventArgs(subscriberUpdateMessage));
}
```

**空格 A**：`OnPublish?.____(...)`  
**空格 B**：第一個參數應填入什麼？代表什麼意思？

## 題目一：作答

**空格 A**：`OnPublish?.Invoke(...)`
**空格 B**：this，代表發送人是Author類別的實例

## 題目二：🤔 邏輯選擇題

在 `EventHandler` 版本的 `User` 類別中，`Subscribe()` 使用 lambda 時，**為什麼要把 lambda 存到 `_publishLambda` 欄位**，而不是每次直接寫 `publisher.OnPublish += (sender, args) => ...`？

**(A)** Lambda 每次建立都是不同實例，`-=` 會找不到對應的委派，無法正確取消訂閱  
**(B)** Lambda 不能直接用於 `EventHandler<T>`，需要先包裝  
**(C)** 這只是個人撰碼風格問題，沒有技術上的差異  
**(D)** 為了避免 Lambda 被 GC 回收

## 題目二：作答

(A)

## 題目三：🚀 執行結果預測

閱讀以下 Observer 版本的 `Main`：

```csharp
Observer.Author author = new("Nintendo", "Game Developer");
Observer.User firstUser = new("Simon");
Observer.User secondUser = new("Cindy");

firstUser.Subscribe(author);
secondUser.Subscribe(author);

Article article = new("Tomodachi Life", "朋友收集 夢想生活", author.Id);
author.Publish(article);

author.RemoveSubscriber(secondUser);
author.Publish(article);
```

請問 **第二次 `author.Publish(article)`** 執行後，`Console.WriteLine` 會被呼叫幾次？是哪些使用者收到通知？

## 題目三：作答

`Console.WriteLine` 只被呼叫1次，只有firstUser會收到通知。
