# 07: 為什麼再次列舉可能得到不同結果？

Status: ready-for-agent
Category: enhancement

**What to build:** 讓讀者在可重複列舉的 yield 範例中執行兩次列舉，觀察計算次數，並比較兩次列舉之間改變輸入的結果。

Blocked by: 05

**相依課程 Ticket：** 05：迭代器方法何時真正執行？

## 目標

辨認重複列舉中的重新計算、副作用與可變輸入。

## 先備知識

05 的延遲執行與迭代器主體執行時機。

## 講解範圍

同一 IEnumerable 的重新列舉、可觀察副作用與可變輸入；與同一列舉器繼續取值、列舉期間修改 List 的情境區分。

## 示範

用明確計數或事件標記記錄每次迭代器主體執行，再於兩次完整列舉之間修改輸入；不讓主範例在走訪 List 期間新增元素。

## 練習與解答

預測兩次輸出與計算次數，修改列舉間的輸入；解釋為何再次取得列舉器不等於沿用上次的進度。

依「簡短說明 → 範例 → 預測輸出 → 執行觀察 → 修改練習」編排；解答放在題目後的獨立區段。
