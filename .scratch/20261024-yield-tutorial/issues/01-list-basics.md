# 01: List 如何保存與提供多個值？

Status: ready-for-agent
Category: enhancement

**What to build:** 提供可直接執行的整數集合單元，讓讀者能新增元素、按索引取值並觀察列舉結果；同時建立後續單元共用的 Console 示範入口。

Blocked by: None

**相依課程 Ticket：** None (can start immediately)

## 目標

區分 List 保存資料、索引取值與 foreach 走訪的用途。

## 先備知識

基本變數、方法呼叫與迴圈；必要語法以最小範例補充。

## 講解範圍

List<int> 建立、Add、索引及 foreach；先不引入 yield 或介面細節。確認可用 SDK 與專案慣例，選定並記錄新專案目標框架，不升級既有範例。

## 示範

從固定整數清單開始，加入一個值，分別顯示索引取值與完整列舉的輸出。

## 練習與解答

預測新增前後的輸出，再修改元素或加入另一個整數；提供預期結果與參考解。

依「簡短說明 → 範例 → 預測輸出 → 執行觀察 → 修改練習」編排；解答放在題目後的獨立區段。
