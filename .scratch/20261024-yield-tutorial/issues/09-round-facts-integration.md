# 09: 如何整理一個回合的多項事實？

Status: ready-for-agent
Category: enhancement

**What to build:** 交付可獨立執行的最小回合事實案例、同條件的 List／yield 版本與練習，完成主線筆記和示範的整體查詢入口。

Blocked by: 08

**相依課程 Ticket：** 08：何時選 yield，何時保存成 List？

## 目標

讀懂、修改並對照回合事實的 List 與 yield 寫法，依需求解釋取捨。

## 先備知識

08 與其傳遞相依的所有主線概念。

## 講解範圍

最小回合資料、必要結果常數或型別、條件判斷與輸出順序；保留原案例和來源脈絡，不依賴外部遊戲系統或原始行號。完成正式筆記、示範及索引的交叉連結。

## 示範

明確定義有效輸入與規則，用固定資料展示零個、一個、多個事實，對相同輸入完整列舉兩個版本並比較值序列；保留勝利與滿血等原情境。

## 練習與解答

預測條件組合的事實與順序，再加入一項明確的新規則，同步更新兩版本及預期結果；提供參考解。

依「簡短說明 → 範例 → 預測輸出 → 執行觀察 → 修改練習」編排；解答放在題目後的獨立區段。

## Acceptance criteria

- [ ] 最小必要型別與規則完整，零／一／多個輸出各有可成立的明確輸入，兩版本對應序列相同。
- [ ] 修改練習有可執行參考解，能展示新增規則後的輸出與順序。
- [ ] 九單元已串成一篇主線筆記與一個 Console 專案，範例與參考解均成功建置、執行並核對。
- [ ] 正式筆記保留原素材、既有題目作答與來源脈絡，移除外部行號依賴；知識庫索引與相對連結正確。
- [ ] 選讀與主線區隔明確；正式內容完整後依專案規則清理暫存內容，合併 main 前確認不含暫存檔案。
- [ ] 本單元包含解釋題判準、實測預測題輸出與修改題參考解，三者與教材敘述一致。
- [ ] 正式技術敘述以官方文件查證，記錄來源、適用版本及驗證日期。
- [ ] 教材與範例沿用共用專案及主線筆記的組織；正式內容新增時同步維護查詢索引與連結，不將暫存文件列入正式索引。
