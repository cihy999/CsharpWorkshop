IEnumerable 約定速查

.NET 10 · 查證日期 2026-11-07

回到課程List 基礎速查

三種讀法

// 元素型別是 int 的清單
List<int> list = new List<int> { 10, 20, 30 };

// 同一個物件，只當成可走訪的序列
IEnumerable<int> sequence = list;

// 回傳型別寫在方法名稱前
private static IEnumerable<int> GetNumbers(List<int> numbers)
{
    return numbers;
}

賦值後的關係

list     → List<int> 物件 A：10, 20, 30
sequence → List<int> 物件 A（同一個）

list.Add(40);   // 之後列舉 sequence 也會看到 40

賦值沒有複製元素，也不是快照；object.ReferenceEquals(list, sequence) 為 True。

宣告型別決定能直接用的操作

寫法List<int>IEnumerable<int>
foreach可以可以
.Add(x)可以CS1061
[i]可以CS0021
.Count可以CS0428
賦值給 List<int>—CS0266

錯誤代碼以 .NET 10 SDK 實測（2026-11-07，啟用 ImplicitUsings）。.Count() 有括號時是 LINQ 擴充方法，可以編譯，不屬於本課範圍。

用語

名稱本課含義
型別參數 T泛型型別中的佔位型別，使用時填入實際型別，例如 int。
介面一份能力約定；實作的類別必須提供約定的成員。不能直接 new。
IEnumerable<T>可以逐一取得 T 的序列；約定只保證能走訪。
宣告型別變數或回傳值寫出的型別；編譯器據此決定可直接使用的成員。
參考類別物件的變數保存參考；多個變數可指向同一物件。

邊界

在 foreach 走訪 List 的途中修改同一份 List，下一次取值會擲出 InvalidOperationException（單元 7 再談）。本課的修改都在列舉之前。
