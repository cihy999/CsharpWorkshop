列舉器協定速查

.NET 10 · 查證日期 2026-11-07

回到課程IEnumerable 約定速查List 基礎速查

手動列舉的標準寫法

using (IEnumerator<int> enumerator = numbers.GetEnumerator())
{
    while (enumerator.MoveNext())
    {
        int number = enumerator.Current;
        // 使用 number
    }
}

本例 numbers 宣告為 IEnumerable<int>；這段是 foreach (int number in numbers) 的概念對照，不是編譯器的逐字輸出。

成員

成員屬於作用
GetEnumerator()序列 IEnumerable<T>交出新的列舉器，從第一個元素之前開始
MoveNext()列舉器前進一格；True＝有元素，False＝已越過結尾
Current列舉器目前元素；只在 MoveNext 回傳 True 後讀
Dispose()列舉器（來自 IDisposable）收尾、釋放資源；交給 using 呼叫

三個元素的時間線

動作回傳位置Current
GetEnumerator()—第一個之前未定義
第 1～3 次 MoveNext()True10 → 20 → 3010 → 20 → 30
第 4 次False最後一個之後未定義
第 5 次以後False仍在結尾未定義

n 個元素需要 n + 1 次 MoveNext()。空序列第一次就回傳 False，foreach 主體不執行。

Current 未定義 ≠ null

官方只說「未定義」。2026-11-07 以 .NET 10 實測不合法時點的讀取：

列舉器來源開始前／結束後讀 Current
List<int>讀到 0
List<string>讀到 null
int[]InvalidOperationException
非泛型 IEnumerator（List 或 Array）InvalidOperationException

實作細節，不可依賴。

用語

名稱本課含義
可列舉序列實作 IEnumerable<T>，能交出列舉器的物件。
列舉器實作 IEnumerator<T>，記住走訪位置的物件。
未定義規格不保證結果；可能是任何值或例外。
Dispose收尾方法；using 離開區塊時一定呼叫。

邊界

要重新走訪，再呼叫一次 GetEnumerator()；Reset() 可能擲出 NotSupportedException。列舉期間修改集合會使列舉器失效（單元 7）。手寫列舉器類別為選讀。
