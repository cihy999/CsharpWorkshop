# List 基礎 Resources

## Knowledge

官方來源查證日期：2026-10-24；API 文件選用 .NET 10，既有 Console 範例以 SDK 10.0.402 驗證。

- [Microsoft Learn：List<T>.Add](https://learn.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.add?view=net-10.0)
  主要閱讀來源。確認 Add 將元素加入清單尾端；先讀 Definition 即可。
- [Microsoft Learn：List<T>.Item](https://learn.microsoft.com/en-us/dotnet/api/system.collections.generic.list-1.item?view=net-10.0)
  確認索引從 0 開始、可讀寫既有位置，及超出範圍的例外。
- [Microsoft Learn：foreach](https://learn.microsoft.com/en-us/dotnet/csharp/language-reference/statements/iteration-statements#the-foreach-statement)
  確認 foreach 逐一取得元素並執行迴圈本體；本單元只使用 List<int>。
