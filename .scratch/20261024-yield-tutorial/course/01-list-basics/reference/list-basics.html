.NET 10 · 查證日期 2026-10-24

四個動作

List<int> numbers = new List<int> { 10, 20, 30 };
numbers.Add(40);      // 尾端新增：10, 20, 30, 40
int x = numbers[1];    // 讀第二個值：20
numbers[1] = 25;       // 替換第二個值，數量不變

foreach (int number in numbers)
{
    Console.WriteLine(number); // 依序輸出 10, 25, 30, 40
}

用語

名稱本課含義
清單 List<int>保存多個 int 的集合。
元素清單中保存的一個值。
索引 index從 0 開始的位置編號；第二個位置是 1。
走訪／列舉逐一取得元素；本例用 foreach 走訪 List。

邊界

三個元素時，有效索引是 0、1、2。此時讀取或寫入 numbers[3] 都會擲出 ArgumentOutOfRangeException；不能藉由寫入不存在的索引新增元素。空清單不能讀索引 0。
