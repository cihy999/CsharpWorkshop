01 / 先保存三個整數

之後我們要比較 List 與 yield 如何提供多項回合事實。先用數字建立直覺：清單可以保存多個值，讓後續程式讀取。

List<int> numbers = new List<int> { 10, 20, 30 };

List<int> 暫時讀作「保存 int 的清單」。numbers 是變數名稱；右邊建立一份起初包含 10、20、30 的清單。

位置從 0 開始編號
索引012
值102030

numbers[1] 讀取第二個元素，所以得到 20。索引指定的是位置。官方：索引讀寫

先試一下：numbers[1] 是多少？

02 / 新增一個，再逐一讀取

numbers.Add(40);

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

Add(40) 把 40 加到尾端，現在第四個位置的索引是 3。官方：Add

foreach 在這份清單中依序讀取元素，每次以 number 接住一個值；Console.WriteLine 將它輸出一行。這段程式只讀取、輸出，沒有移除元素。官方：foreach

走訪結束後，清單有幾個元素？

03 / 先預測，再執行

把三個動作接起來。先讀程式，想好每一行輸出，再按核對。

List<int> numbers = new List<int> { 10, 20, 30 };
numbers.Add(40);

Console.WriteLine(numbers[0]);
Console.WriteLine(numbers[3]);

foreach (int number in numbers)
{
    Console.WriteLine(number);
}

預測題解答與原因
10
40
10
20
30
40

先按索引讀兩個值，再走訪四個元素。索引讀取不會把值取走，所以 10 與 40 會再次出現在走訪輸出。

執行真正的 C# 範例

開啟本單元的 YieldTutorial 資料夾，在該資料夾的終端機執行：

dotnet run -- 01

這個完整示範還會先列出「新增前」的三個值，並在各段加上標題。核對它的「索引 0」、「索引 3」與「新增後」三段，是否符合你的預測。完整輸出與 repo 根目錄執行指令

04 / 自己改一次

在 ListBasics.cs 的 Run() 中，找到 numbers.Add(40);，在它後面、最後一次走訪前加入兩行：

  1. 將第二個元素改為 25。
  2. 將 50 新增到清單尾端。

先想好清單最後的五個值，再動手修改、重新執行 dotnet run -- 01。

修改題參考解
numbers[1] = 25;
numbers.Add(50);

「新增後」一段會依序輸出 10、25、30、40、50。索引賦值替換既有位置；Add 才會新增元素。第一次走訪發生在修改前，因此「新增前」仍為 10、20、30。

專案另附獨立解答：dotnet run -- 01-answer，會輸出修改後的索引 1 與完整清單。

解釋題判準

清單保存多個值；索引指定一個位置來讀寫；foreach 逐一取得元素。能指出對應程式碼，並說明本例讀取不會移除元素即可。
