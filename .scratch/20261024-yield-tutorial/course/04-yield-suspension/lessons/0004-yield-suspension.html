01 / return 交出整份，yield return 交出一個

兩個方法都回傳 IEnumerable<int>，交出的值也都是 10、20、30：

static IEnumerable<int> WithReturn()
{
    List<int> numbers = new List<int> { 10, 20, 30 };
    return numbers;          // 交出整份 List，方法結束
}

static IEnumerable<int> WithYield()
{
    yield return 10;         // 交出 10，停在這裡
    yield return 20;         // 下次從這行開始
    yield return 30;
}                            // 走到結尾，序列結束
一般 returnyield return
交出什麼整份結果，一次交出下一個元素，一次一個
交出之後方法結束方法暫停，等下次要求
區域變數不再使用暫停期間保留

主體中有 yield return 的方法稱為迭代器，回傳型別要寫 IEnumerable<T> 或 IEnumerator<T>。官方：yield · 官方：return

yield return 交出一個值之後，方法接著會？

兩種寫法不能混在同一個方法。C# 規格規定迭代器裡不能出現 return 陳述式。2026-11-21 以 .NET 10 實測：同一方法裡有 yield return 10; 又寫 return new List<int> { 20 };，得到 CS1622「無法從迭代器傳回值」；回傳型別寫成 List<int> 卻用 yield return，得到 CS1624。官方：迭代器的結構規則

方法裡已有 yield return 10;，還能寫 return list; 嗎？

02 / 每次 MoveNext，跑到下一個 yield return

使用序列的一方叫消費端（例如 foreach），迭代器方法叫產生端。上一課的 MoveNext() 在這裡有了具體意義：

產生端執行到MoveNext() 回傳Current
yield return 運算式;True這個運算式的值
方法結尾False未定義，不讀

第一次 MoveNext() 從方法開頭執行；之後每一次都從上次暫停的 yield return 的下一行繼續，直到下一個 yield return 或方法結尾。兩次要求之間，產生端不會自己往下跑。官方：迭代器的執行

第二次 MoveNext() 時，產生端從哪裡開始執行？

呼叫方法、GetEnumerator() 與第一次 MoveNext() 各自發生在什麼時候，留到單元 5。這一課只看「每次要求元素」時發生什麼。

03 / 區域變數會記得

暫停時，所有區域變數的值和暫停位置都會保存；繼續時還原。C# 規格：MoveNext 的行為 以下是完整範例中的 CountUp：

private static IEnumerable<int> CountUp()
{
    int count = 0;
    Console.WriteLine("[產生端] 從方法開頭執行，count = " + count);

    count += 10;
    Console.WriteLine("[產生端] 位置 1：產出 count = " + count);
    yield return count; // 位置 1

    Console.WriteLine("[產生端] 從位置 1 之後繼續，count = " + count);
    count += 10;
    Console.WriteLine("[產生端] 位置 2：產出 count = " + count);
    yield return count; // 位置 2

    Console.WriteLine("[產生端] 從位置 2 之後繼續，count = " + count);
    count += 10;
    Console.WriteLine("[產生端] 位置 3：產出 count = " + count);
    yield return count; // 位置 3

    Console.WriteLine("[產生端] 從位置 3 之後繼續，走到方法結尾");
}
第 2 次 MoveNext() 時，「從位置 1 之後繼續」印出的 count 是？

保存的是變數本身的值。若變數參照 List 這類物件，物件內容在暫停期間仍可能被別的程式改掉；這留到單元 7。

static IEnumerable<int> Numbers()
{
    int total = 0;
    Console.WriteLine("A");
    for (int i = 1; i <= 3; i++)
    {
        total += i;
        yield return total;
        Console.WriteLine("B" + i);
    }
    Console.WriteLine("C");
}

foreach (int n in Numbers())
{
    Console.WriteLine(n);
}

第一次要求時，方法從開頭印出 A，進入迴圈後交出 total = 1 並暫停，foreach 印出 1。下一次要求從 yield return 的下一行繼續，印出 B1；迴圈的 i 與 total 都保留，所以接著交出 1 + 2 = 3。第四次要求時印出 B3、離開迴圈印出 C，方法走到結尾，foreach 結束。這段程式於 2026-11-21 以 .NET 10 在暫存專案實測。

private static IEnumerable<int> CountUpModified()
{
    int count = 1;
    Console.WriteLine("[產生端] 從方法開頭執行，count = " + count);

    count *= 2;
    Console.WriteLine("[產生端] 位置 1：產出 count = " + count);
    yield return count; // 位置 1

    Console.WriteLine("[產生端] 從位置 1 之後繼續，count = " + count);
    Console.WriteLine("[產生端] 新增的位置：產出 count + 100 = " + (count + 100));
    yield return count + 100; // 新增的位置

    Console.WriteLine("[產生端] 從新增的位置之後繼續，count = " + count);
    count *= 2;
    Console.WriteLine("[產生端] 位置 2：產出 count = " + count);
    yield return count; // 位置 2

    Console.WriteLine("[產生端] 從位置 2 之後繼續，count = " + count);
    count *= 2;
    Console.WriteLine("[產生端] 位置 3：產出 count = " + count);
    yield return count; // 位置 3

    Console.WriteLine("[產生端] 從位置 3 之後繼續，走到方法結尾");
}

int received = 0;

foreach (int number in CountUpModified())
{
    received++;
    Console.WriteLine("[消費端] 取得 " + number);
}

Console.WriteLine("[消費端] 共取得 " + received + " 個值");

static IEnumerable<int> Broken()
{
    yield return 10;
    return new List<int> { 20 };

解釋題判準

能說出三點即可：第 1 次 MoveNext() 停在位置 1 時保存了 count = 10 與暫停位置，第 2 次從下一行繼續，不會回到開頭重新執行 int count = 0；印出那行在 count += 10 之前，所以是 10。Broken 有 yield return，是迭代器，迭代器中不能用 return 回傳值（CS1622）；改成 yield return 20;，或整個方法改用 List 與 return。一般 return 交出整份結果後方法結束；yield return 每次交出一個元素後暫停，等下一次要求才繼續。

稍後或隔天，不看教材寫一個依序 yield return 1、2、3 的方法，在每個 yield return 前後各加一行標記；先在紙上寫出 foreach 走完它的輸出，再執行核對。寫不出來時再查速查表。
