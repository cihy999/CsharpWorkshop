yield 暫停與繼續速查

.NET 10 · 查證日期 2026-11-21

回到課程列舉器協定速查IEnumerable 約定速查

最小迭代器方法

private static IEnumerable<int> GetNumbers()
{
    yield return 10;   // 交出 10，暫停
    yield return 20;   // 下次從這行繼續
    yield return 30;
}                      // 走到結尾：MoveNext 回傳 False

return 與 yield return

一般 returnyield return 運算式;
交出整份結果，一次下一個元素，一次一個
之後方法結束方法暫停，下次從下一行繼續
區域變數不再使用暫停期間保留
結束時機執行到 return方法結尾或 yield break（單元 6）

MoveNext 與產生端

第幾次 MoveNext()產生端從哪裡執行執行到哪裡停
第 1 次方法開頭第一個 yield return
之後每次上次暫停的 yield return 的下一行下一個 yield return 或方法結尾
停在MoveNext() 回傳Current
yield return 運算式;True運算式的值
方法結尾False未定義，不讀

兩次要求之間，產生端不會自己往下跑。暫停時保存所有區域變數的值與暫停位置；保存的是變數的值，變數參照的物件內容仍可能被修改（單元 7）。

寫法規則

規則違反時
回傳型別用 IEnumerable<T> 或 IEnumerator<T>寫成 List<int>：CS1624（實測）
迭代器中不能用 return 回傳值與 yield return 混寫：CS1622（實測）
yield return 後面一定要有運算式yield return;：CS1627（官方錯誤清單）

標示「實測」者於 2026-11-21 以 .NET 10 在暫存專案驗證。

其他限制：參數不能是 ref、out、in；不能寫在 lambda 中；yield return 不能放在 catch、finally 或帶 catch 的 try 中。

用語

名稱本課含義
迭代器（方法）主體含有 yield return、回傳可列舉介面的方法。
產生端產出元素的一方，本課指迭代器方法。
消費端要求元素的一方，例如 foreach 或手動呼叫 MoveNext() 的程式。
暫停交出元素後停在該 yield return，保存區域變數與位置。
繼續下一次 MoveNext() 從暫停處的下一行往下執行。

邊界

呼叫方法、GetEnumerator() 與第一次 MoveNext() 的時間點在單元 5；yield break、中途 break 與 finally 清理在單元 6。編譯器如何實作列舉器屬選讀，本課只依公開行為觀察。
