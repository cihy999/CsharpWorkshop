# 05-deferred-execution 課堂筆記

## 課堂練習的回答

### 01 / 呼叫方法，主體一行都還沒跑

呼叫 Steps() 並取得列舉器後，產生端印出了？

答：一行也沒有印出。

### 02 / 要幾個，就跑到第幾個

情境 2 只要求 2 個元素，「從產出 2 之後繼續」會印出嗎？

答：不會，沒人再要求。

### 03 / 延遲來自 yield，不是回傳型別

StepsWithList() 也回傳 IEnumerable<int>，呼叫時主體會？

答：呼叫時立刻執行。

### 04 / 明確事件標記

答：

```text
A
B
P
C1
Q
D2
E
```

### 05 / 移動一行，再預測

答：

- 情境一：0次，不出現。
- 情境二：0次，不出現。
- 情境三：1次，要執行第 3 次 MoveNext() 才會出現。

### 合上教材，用自己的話說

情境 1 呼叫了 Steps() 也取得了列舉器，產生端卻一行都沒印。主體什麼時候才開始執行？情境 2 為什麼看不到「從產出 2 之後繼續」？

答：

1. 只有呼叫列舉器 MoveNext() 時，Steps()主體才會開始執行。
2. 因為只執行到 `yield return 2;`，位置停留在那裏。

有人說：「這個方法回傳 IEnumerable<int>，所以呼叫時不會執行。」用本課的對照說明這句話哪裡不對。

答：要根據方法內部是使用 yield return 還是 return 來判斷，兩者回傳值都是 IEnumerable<int>，光從回傳值無法判斷。
